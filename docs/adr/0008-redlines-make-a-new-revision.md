# A redline makes a new revision of the DWG, with each change clouded, and never touches the original

Zach wants a marked-up PDF to "redline the dwg file with my pdf markups and replace my lines and drawn valves or objects with nice blocks." A redline job finds the sheet's DWG through the drawing index, and writes a copy of it in which each change is drawn properly (blocks for the valves and devices he sketched, clean linework for his lines), each inside a revision cloud on its own layer, with a PDF plotted from the copy. The original DWG is never changed. We considered tracing his markups onto a red layer for a drafter to apply, which loses the point of the job, and editing the DWG in place, which leaves nothing to compare against when the agent gets a change wrong.

The results go to the job's project folder, and the plotted PDF can be placed in Vellum beside Zach's markup to compare.
