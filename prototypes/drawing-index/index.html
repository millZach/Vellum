The four choices

1. Which part of Dropbox to scan

aOne projects folder you namerecommended: faster first scan, nothing personal indexed.
bA short list of folders you pick, in a settings file on the laptop.
cAll of Dropbox: slowest first scan.

2. How the indexer runs

aAlways on, starts with Windows, watches Dropboxrecommended: a plot request is answered in seconds while the laptop is on.
bA scheduled task every few minutes: simpler, plot requests can wait minutes.
cOnly when you run it by hand.

3. Where title block fields come from

aDWG title block attributes, falling back to the PDF's textrecommended.
bThe PDF's text only: no AutoCAD needed, less exact, only drawings with a PDF.
cFile and folder names only, for now.

4. PDFs with no DWG behind them (vendor drawings)

aList them toorecommended: searchable and openable, just not redlined back to a DWG.
bDWGs only.
